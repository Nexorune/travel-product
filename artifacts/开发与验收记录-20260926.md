# v0.3 开发与验收记录

## 用户本轮决定

- 开始开发旅游产品 v0.3。

## 实现

双入口、可持续保存的旅行条件、候选比较、逐日时间线、真实地图组件、异步任务进度、补充澄清、取消、修改差异审阅与确认、匿名会话归属、SQLite、版本冲突、幂等、快照撤销、锁定保护、局部日期范围保护、导出、数据清除、服务设置。模型可配置 chat / responses，高德查询适配器，可选 Tavily。

运行界面只使用明确标识的交互示例或真实服务数据，没有配置密钥时拒绝生成真实规划。测试 fixture 仅存在于 tests/，不进入运行页面。

## 实际验证

- npm run build：通过；地图拆为延迟加载包。
- npm run lint：通过，最终无告警。
- npm test：15 项通过。覆盖 schema、未知工具拒绝、事实来源、锁定、范围外编辑、确认写入、匿名归属、版本冲突、幂等、无配置 503、取消前置、chat / responses 适配和地图响应形状。测试不验证真实模型质量。
- 浏览器：已知目的地入口正确、5 天切换、锁定禁用删除、解锁与跨天移动、刷新恢复地点及 DAY2 选择、地图示例与服务设置。
- 390px 视口无横向溢出；320px 与矮桌面视口另有最终检查输出。
- 服务页面 HTTP 200，health HTTP 200 且 ready=false（符合未配置状态）。
- 本轮修复：已知入口误入探索表单；旧样例经纬度顺序导致恢复失败；存储不可用时捕获异常；锁定、局部范围与延迟响应保护。
